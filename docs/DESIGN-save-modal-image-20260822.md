# 설계 — 저장·수정 화면 이미지 저장 (2026-08-22)

## 목적
저장·수정 미리보기에서 목록 「이미지 저장」과 같은 캡션 JPEG를 바로 넣는다.
하단 「저장」은 앱 목록만 유지해 연속 촬영 속도를 깨지 않는다.

## 동작
1. 미리보기 아래 **이미지 저장**
2. 앱에 저장 또는 수정 (`skipIdleCaptionGallery`)
3. 기존 `saveStampsAsJpegToGallery` 1장
4. 완료 알림 후 모달 닫기
5. 설정 `캡션만`/`원본+캡션` idle 캡션은 건너뛰고, 원본이 필요하면 idle 원본만 유지

## 비범위
확대 화면 저장, 미리보기 스크린샷, 하단 3버튼, 신규 npm, 연속 촬영 자동 캡션
