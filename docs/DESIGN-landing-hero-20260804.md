# DESIGN — 랜딩 히어로 배너 (2026-08-04)

## 목적
홈(`/`) 첫 화면을 다운로드 안내 목록에서, 현장 기록 앱을 한눈에 보여주는 히어로 구성으로 바꿉니다.

## 범위 (최소 수정)
- `public/landing.html` 레이아웃·카피·스타일
- `public/help.html` 웹 진입 안내 한 문단
- 히어로 PNG 3장 (`public/` + `assets/` 동일 사본)
- 되돌리기: `restore-landing-hero.bat` → `public.pre-landing-hero/`

앱 네이티브 코드·API·의존성 패키지는 변경하지 않습니다.

## 시각 자산
| 파일 | 용도 | 비율 |
|------|------|------|
| `hero-banner-wide.png` | PC·넓은 화면 히어로 배경 | 16:9 |
| `hero-banner-tall.png` | 좁은 화면 히어로 배경 | 9:16 |
| `hero-product.png` | 본문「현장·시설」섹션 예시 | 4:3 |

이미지에는 한글·로고를 넣지 않았습니다. 문구는 HTML의 `system-ui`로만 표시합니다.
