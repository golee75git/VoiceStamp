# 보안·라이선스 — 앨범 EXIF 촬영 위치 (2026-08-03)

## 보안

| 항목 | 판단 |
|------|------|
| 데이터 | EXIF GPS는 기기 로컬에서만 읽고, 기존 장소 조회(학교 DB·카카오)와 동일 경로로 장소명 생성. 새 서버 엔드포인트 없음 |
| 권한 | 앨범 권한은 기존과 동일. EXIF 좌표 사용 시 **위치 권한 없이도** 좌표는 채울 수 있으나, 장소명 조회는 설정 `isGpsPlaceEnabled`·기존 카카오 키 정책에 따름 |
| Play | 위치 수집 목적이 「사진에 기록된 촬영 위치」로 명확. 현재 위치 오용 방지(`allowLiveLocationFallback=false`) |
| 입력 | EXIF 숫자만 파싱. 문자열 주입 경로 없음 |

## 글꼴

시스템 UI 글꼴만 사용. OFL 폰트 파일 추가 없음.

## 의존성

신규 npm 없음. `expo-image-picker`·`expo-location` MIT. GPL 강제 추가 없음.

## 특허

특허 비침해를 보장하지 않음. EXIF GPS 읽기·좌표로 장소 라벨 조회는 일반적 구성이며, 필요 시 제품 측에서 별도 검토.
