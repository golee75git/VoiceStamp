# LEG-07 — 위치기반서비스사업자 신고 검토

| 항목 | 내용 |
|------|------|
| 작성 | 2026-09-10 |

| 근거 법령 | 「위치정보의 보호 및 이용 등에 관한 법률」 제9조·제43조 |

> **법무 확정 문서 아님.** 공개 검색 결과 기반 내부 조사 정리이며, Play 스토어 **정식(Production) 출시 전** 위치정보지원센터(lbsc.kr) 또는 법률 전문가의 정식 확인을 권장합니다.

---

## 1. 왜 검토 대상인가

VoiceStamp는 GPS 좌표를 **카카오 로컬 API로 전송해 주소·장소명으로 변환**하는 기능이 있습니다(`locationService.ts` → `kakaoLocal.ts`, 6초 타임아웃·결과 캐시).

- 「위치정보의 보호 및 이용 등에 관한 법률」 제9조: **특정 개인의 위치정보(GPS 좌표 등)를 수집·이용해 서비스를 제공**하면 위치기반서비스사업자 **신고** 대상.
- 서버에 원본 좌표를 저장하지 않고 **결과(주소)만 받아쓰는 경우도 신고 대상**이라는 설명이 있음 — `PRIVACY.md` §2.3에 "좌표 자체는 SQLite에 저장하지 않음"이라 되어 있으나, 이는 **개인정보 보관** 관점의 안전장치일 뿐 **신고 의무 자체를 면제하지는 않을 가능성**이 있음.
- 반대로 **주소(텍스트) 자체는 개인위치정보가 아니므로** 신고 대상이 아니라는 설명도 있어, **로컬 학교 DB 매칭**(기기 내 좌표 비교, 외부 전송 없음 — `schoolLookup.ts`)이 신고 대상인지는 불명확 → 정식 확인 필요.

## 2. 소상공인·1인 창조기업 유예

- 「소상공인 보호 및 지원에 관한 법률」상 소상공인 또는 「1인 창조기업 육성에 관한 법률」상 1인 창조기업은 **사업 개시 후 1개월간 신고 없이 서비스 가능**.
- 1개월 경과 후에는 **반드시 신고** 필요 (소상공인등의 위치기반서비스 사업신고 — 중소기업현황정보시스템 확인서 등 별도 서류).
- 개발자(이형우)의 사업자 지위 확인 후 해당 여부 판단 필요.

## 3. 신고 절차 (해당 시)

| 항목 | 내용 |

| 제출서류 | 신고 신청서, 사업계획서, 사업자등록증/법인등기부등본, 위치정보 보호조치 증명서류 등 |

## 4. 미신고 리스크

- **형사처벌:** 3년 이하 징역 또는 3천만원 이하 벌금 (법 제43조 계열)
- 신고 없이 사업 중단 등에 과태료 부과 사례 존재

## 5. 조치 항목

- [ ] 위치정보지원센터(lbsc.kr) 또는 법률 전문가에게 카카오 로컬 API 좌표→주소 변환 기능의 신고 대상 여부 정식 확인
- [ ] 로컬 학교 DB 매칭(외부 전송 없음)도 신고 대상인지 별도 확인
- [ ] 신고 대상 확정 시 소상공인/1인 창조기업 요건 및 유예기간 활용 여부 결정
- [ ] 신고 대상이면 Play Production 출시 전 `emsit.go.kr` 신고 완료
- [ ] 신고 결과를 `PRIVACY.md`·`PLAY-DATA-SAFETY.md`에 반영

## 6. 방통위·위치정보지원센터 문의 사항 (초안)

전자민원센터(emsit.go.kr) 또는 위치정보지원센터(lbsc.kr) 상담 시 아래 항목을 순서대로 확인 권장. VoiceStamp의 실제 동작(§1)을 구체적으로 설명하며 질의.

### 6.1 신고 대상 여부 판단
- [ ] 앱이 GPS 좌표를 **카카오 로컬 API로 전송**하고, 결과로 받은 **주소 문자열만** 저장·표시(원본 좌표는 서버·DB에 미보관)하는 방식도 「위치정보법」 제9조상 위치기반서비스사업 **신고 대상**인지?
- [ ] 위치정보를 **직접 수집·가공하는 것이 아니라, 이미 위치정보사업자(카카오)로 등록된 제3자 API를 호출**만 하는 경우에도 앱 운영자가 별도로 신고해야 하는지, 아니면 카카오 측 등록으로 갈음되는지?
- [ ] **기기 내 로컬 DB(전국 학교 위치 좌표)와 GPS 좌표를 기기 안에서만 비교**하여 학교명을 표시하고 외부로 전혀 전송하지 않는 기능도 신고 대상인지?
- [ ] 위치정보를 **1회성·비연속으로만** 사용(실시간 추적·이동경로 저장 없음, 촬영 시점 좌표 1건만 일시 조회)하는 경우에도 "특정 개인의 위치정보 수집·이용"에 해당하는지?

### 6.2 개발자·사업자 지위
- [ ] **사업자등록이 없는 개인 개발자**도 위치기반서비스사업 신고 대상이 되는지, 신고 시 사업자등록증 대신 제출 가능한 서류는?
- [ ] 「1인 창조기업 육성에 관한 법률」상 1인 창조기업 요건에 해당하는지 확인하는 절차와, 해당 시 **1개월 유예기간의 기산일**(최초 배포일 vs 기능 추가일) 기준은?
- [ ] 무료 앱으로 수익이 발생하지 않는 경우도 "사업"으로 보아 신고 의무가 발생하는지?

### 6.3 배포 채널별 적용 범위
- [ ] Android APK(자체 배포·Play 스토어)와 Web(Vercel) 두 채널 모두에서 위치 기능을 제공하는데, **하나의 신고로 두 채널을 모두 포괄**할 수 있는지, 아니면 채널별로 별도 신고가 필요한지?
- [ ] 테스터 채널(dated APK, 소규모 내부 배포)과 정식 Play Production 배포를 구분해 신고 시점을 다르게 가져갈 수 있는지(예: 테스터 단계는 유예기간 내 처리, Production 전환 시점에 정식 신고)?

### 6.4 절차
- [ ] 신고 접수 후 처리 기간(약 2주) 동안 서비스를 계속 운영해도 되는지, 신고 완료 전 배포가 제한되는 경우가 있는지?
- [ ] 이미 배포 중인 상태에서 신고할 경우(사후 신고) 추가 불이익이 있는지, 자진 신고 시 감면 제도가 있는지?
