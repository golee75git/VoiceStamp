# 설계 — 연결 비교 엑셀 사진 가로 (2026-08-23)

## 목적
연결 비교에서 고른 이음 스탬프로 엑셀을 만들 때도, 저장 목록·취합 수신과 같이 사진 가로 px와 글자 크기를 고른다.

## 동작
1. 연결 비교에서 카드 선택 후 「엑셀」
2. 가로 px(120–800) · 칩 180/240/320/480/800 · 글자 작음/보통/큼
3. 확인 시에만 `createStampsXlsx`에 `previewWidthPx`·`fontSizePt` 전달
4. 마지막 값은 수신·목록 엑셀과 같은 기기 설정 키에 저장

## 비범위
엑셀 엔진 교체, 신규 npm, JPEG/QR 합성, 전체 `listStamps()` 재조회

## 헬스체크
번들 A/B/C 재패치 없음. 엑셀 모듈은 확인 버튼 시에만 로드. 선택분만 내보냄.
