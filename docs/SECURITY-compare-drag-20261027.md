# 보안·라이선스·특허 점검 — 연결 비교 길게 눌러 이동 (2026-10-27)

## 범위
- 연결 비교에서 사진을 길게 누른 뒤 가로로 끌면 이번 화면의 순서만 바뀐다.
- 앞·뒤 버튼은 그대로다. 순서는 저장하지 않는다.

## 보안
- 터치 좌표는 칸 수만 계산하고 저장·전송하지 않는다.
- 네트워크·새 권한·새 저장 컬럼 없음.
- 보내는 중에는 끌기를 끈다.

## 라이선스
- 패키지 추가 없음. 이미 있는 `react-native-gesture-handler` 2.31.1 MIT, `react-native-reanimated` 4.3.1 MIT만 사용.
- 글꼴 파일 추가 없음. GPL 신규 없음.

## 특허
- 길게 누른 뒤 가로로 끌어 목록 칸을 바꾸는 일반 화면 동작이다.
- **특허 비침해를 보장하지 않음.** 별도로 청구항과 맞춰 볼 신규 기술 구성은 없다.

## Play 스토어
- 권한·데이터 수집·서명 변경 없음.
