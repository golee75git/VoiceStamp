# 보안·라이선스·특허 점검 — 연결 비교 끝에서 이어서 이동 (2026-10-27)

## 범위
- 연결 비교에서 사진을 길게 눌러 끌 때, 화면 끝에서 목록이 따라 움직인다.
- 이동한 칸은 손가락 거리와 그때 스크롤된 거리를 더해 센다. 순서는 저장하지 않는다.

## 보안
- 터치 좌표와 스크롤 위치는 칸 계산에만 쓰고 저장·전송하지 않는다.
- 네트워크·새 권한·새 패키지 없음.

## 라이선스
- 패키지 추가 없음. 글꼴 추가 없음. GPL 신규 없음.

## 특허
- 목록 끝에서 스크롤을 이어 항목 위치를 바꾸는 일반 화면 동작이다.
- **특허 비침해를 보장하지 않음.** 별도로 청구항과 맞춰 볼 신규 기술 구성은 없다.

## Play 스토어
