# 설계 — 이음 제목 번호 (2026-08-23)

## 목적
이음 저장 초안은 처음 제목을 유지하고 `(이음 n)`만 올린다.
제목 칸은 잠그지 않으며, 저장 버튼은 칸 값을 다시 쓰지 않는다.

## 동작
1. 이음 저장 화면 열림
2. `parent_id` COUNT(휴지통 제외) + 1
3. 처음 제목에서 기존 `(이음)`·`(이음 n)`·`(후속)`만 제거한 뒤 `(이음 n)` 부착
4. 사용자가 칸을 고치면 그 값을 저장

## 비범위
기존 행 UPDATE로 번호 재매김, 제목 칸 잠금, 목록 `이음 ·` 접두어 변경, JPEG/QR 합성, 신규 npm

## 헬스체크
번들 A/B/C 재패치 없음. COUNT는 `idx_stamps_parent_id`만 사용. `listStamps()` 전체 로드 없음.
