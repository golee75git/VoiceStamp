# 보안·라이선스·특허 점검 — 연결 비교 순서 · 목록 제목 바꾸기 (2026-10-27)

## 범위
- 연결 비교 화면에서 앞·뒤로 이번 비교와 PDF·엑셀에 쓰는 순서만 바꾼다. 기기에 순서를 저장하지 않는다.
- 저장 목록에서 고른 사진의 저장 제목을 같은 글(최대 80자)로 바꾼다. 메모·장소·사진 파일은 그대로다.

## 보안
- 제목은 SQLite 바인딩 인자로만 넣는다. 문자열을 SQL에 이어 붙이지 않는다.
- 제어 문자는 빼고, 길이는 저장 화면과 같이 80자로 자른다.
- 휴지통에 있는 행(`deleted_at`)은 바꾸지 않는다. 한 트랜잭션으로 적용한다.
- 순서 변경은 화면 메모리만 바꾼다. 네트워크·새 권한·새 저장 컬럼 없음.
- 이미 갤러리에 저장한 JPEG의 글자는 이 제목 변경으로 다시 쓰지 않는다.

## 라이선스
- 패키지 추가 없음. GPL 신규 없음. 글꼴 파일 추가 없음(기기 기본 글자).

## 특허
- 목록 순서를 이웃과 바꾸고, 고른 행의 제목 칸만 같은 값으로 갱신하는 일반 화면 동작이다.
- **특허 비침해를 보장하지 않음.** 별도로 청구항과 맞춰 볼 신규 기술 구성은 없다.

## Play 스토어
- 권한·데이터 수집·서명 변경 없음. 제목은 기존과 같이 기기 안에만 저장된다.
