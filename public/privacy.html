개인정보 처리 안내

문서 버전 1.0 · 최종 수정 2026-06-09 · Android APK, Web (Vercel)

VoiceStamp는 사진·제목·메모를 사용자 기기(또는 브라우저)에 저장합니다. 운영자가 별도 서버에 계정·사진을 모으지 않습니다.

1. 수집·이용 정보

정보목적보관
사진스탬프·PDF기기 파일 + SQLite (웹: 브라우저)
제목·메모표시·PDF·음성 입력SQLite
GPS 좌표제목에 장소 반영 (카카오 API)좌표는 DB에 저장하지 않음

2. 기기 권한

  • 카메라 — 사진 촬영
  • 마이크 — 음성으로 제목·메모 입력
  • 위치 — 제목 자동 장소 (거부 시 날짜·시간만)
  • 사진/저장소 — 갤러리 백업 (APK)

3. 제3자 제공

  • 카카오 로컬 API — GPS 좌표를 주소·건물명으로 변환 (키 설정 시)
  • OS 음성 인식 — 음성을 텍스트로 변환 (기기/OS 정책 적용)
  • 웹 랜딩 방문 통계 — 홈페이지(/) 하단 집계용. 브라우저 localStorage로 같은 날 재방문은 1회만 반영하며, 익명 합계 숫자만 외부 집계 API(CountAPI)로 전달합니다. 사진·제목·메모 등 앱 데이터는 전송하지 않습니다.

3.1 선택: 개인정보 가리기 (Android)

설정에서 켠 뒤 저장 화면에서 적용합니다. 얼굴·숫자 글자 영역을 기기 안 Google ML Kit으로만 분석·모자이크합니다. 자동으로 잡히지 않은 곳은 화면에서 탭해 영역을 직접 지정할 수 있습니다(생성형 지우기 없음·단순 모자이크). 사진은 VoiceStamp 서버로 전송되지 않으며, 신원 식별·생성형 AI는 사용하지 않습니다. 기본값은 끔입니다.

3.2 선택: 사진 글자로 제목·메모 (Android)

설정에서 켠 뒤 저장 화면의 「글자 읽어 채우기」로, 사진 속 글자를 기기 안 Google ML Kit 한글 문자 인식으로만 읽어 제목·메모 초안을 채웁니다. 긴 초안은 기기 화면에서만 스크롤해 확인·수정합니다. 사진은 VoiceStamp 서버로 전송되지 않으며, 생성형 AI로 문장을 새로 쓰지 않습니다. 기본값은 끔입니다.

사진 URL → QR

설정에서 켠 뒤 저장 화면에서 확인한 http(s) URL만 기기 안에서 QR 이미지로 만들어 「사진 아래(별도 영역)」내보내기/갤러리 JPEG에 합성합니다. 「URL 찾아 QR」은 Android에서 위와 같은 온디바이스 OCR로 주소 후보만 찾으며, URL을 열어 보거나 서버로 보내지 않습니다. 기본값은 끔입니다.

3.3 선택: 장면 키워드 (Android)

설정에서 「촬영 후 장면 키워드 자동 입력」을 켠 뒤 저장 화면이 열리면, 사진을 기기 안 Google ML Kit Image Labeling으로만 분석해 메모에 장면·사물 키워드 초안을 넣습니다. 사진은 VoiceStamp 서버로 전송되지 않으며, 자연어 긴 문장 설명이 아닙니다. 기본값은 끔입니다.

4. 보관·파기

기본 클라우드 동기화는 없습니다. 설정의 사업 취합(선택)을 켠 경우에만 한국 리전 일시 저장소로 전송될 수 있습니다. 앱 삭제·휴지통·브라우저 데이터 삭제로 기기 데이터를 제거할 수 있습니다.

5. 보안·이용자 권리

데이터는 기기에 평문 저장됩니다. 권한은 OS 설정에서 거부할 수 있습니다.

6. 아동

만 14세 미만을 대상으로 하지 않습니다.
