도움말

시작하기

APK: 카메라로 촬영 → 저장 모달에서 제목·메모 입력 → 저장.

웹: 저장 목록 → 앨범에서 사진 가져오기.

설정에서 일반 촬영 카메라(시스템 / 앱 내)와 연속 촬영 카메라를 고를 수 있습니다. 앱 내 카메라는 확인 화면 없이 빠르며, 미리보기에서 1x·3x·5x 배율 버튼과 핀치·더블탭으로 확대할 수 있습니다. 앱 내 촬영음은 설정에서 켜기/끄기할 수 있습니다(시스템 카메라는 기기 설정). 시스템 카메라는 화질·줌에 유리합니다.

스탬프 저장

  • 제목: 촬영 시각이 먼저 표시되고, 위치 권한 허용 시 구·동·건물명이 추가될 수 있습니다.
  • 장소: 위치 조회를 사용하면 GPS·장소명이 채워집니다. 설정에서 위치 조회를 끄면 직전에 입력·저장한 장소가 자동으로 표시됩니다.
  • 층: 설정의 층 선택이 「학교일 때만」이면 장소·폴더명에 학교(초·중·고·대학 등)가 있을 때만 층 칩이 보이고, 직전 층도 학교에만 이어집니다. 비학교 장소에는 층이 저장되지 않습니다.
  • 저장 폴더: YYYYMMDD_장소명 형식. [선택]으로 기존 폴더 선택 가능.
  • 사진 미리보기 탭 → 확대·이동·크롭. 닫기·적용은 설정의 카메라 메뉴 위치(손잡이)와 같은쪽 하단(사진 버리기 위)에 표시됩니다.
  • 마이크 버튼으로 제목·메모·장소 음성 입력 (APK).

저장 목록

  • 카드 탭 → 수정 · 길게 누르기 → 여러 개 선택
  • 선택 후 PDF 만들기·저장·공유, 이미지 저장, 휴지통 이동
  • 제목·메모 검색창 앞 마이크로 음성 검색 (APK). 헤더 「설정」에서 PDF·폴더·손잡이 등 변경
  • 목록·휴지통은 작은 미리보기(썸네일)로 표시해 사진이 많아도 스크롤이 가벼워집니다. 수정·PDF·내보내기는 원본을 사용합니다.

설정

  • 설정 화면은 바로 열리며, 저장된 값은 곧 반영됩니다. 하단에 뒤로가기와 저장이 같은 줄에 고정되어 있습니다.
  • 각 선택 칩에 · 기본이 붙은 항목이 처음 설치 시 기본값입니다. 원래대로 쓰려면 해당 칩을 고른 뒤 저장하세요.
  • 층 선택: 사용 안 함 / 학교일 때만(기본) / 항상 표시. 층 표기: 장소 뒤에 붙이기 또는 커서 위치에 삽입.
  • PDF·폴더·카메라·위치·갤러리 등 대부분의 동작은 설정에서 변경합니다.

Android 뒤로가기

  • 목록·설정 → 카메라 (설정은 들어온 화면으로 복귀)
  • 카메라 → 앱 종료 확인

웹 제한

  • 갤러리 앨범 백업 없음
  • 카메라·음성은 브라우저·환경에 따라 제한될 수 있음

문제 해결

  • 위치가 안 나옴 → GPS·위치 권한·카카오 API 키 확인. 위치 조회를 끈 경우 장소는 직접 입력·수정하며, 다음 촬영 시 직전 장소가 자동 표시됩니다.
  • APK 키 변경 후 → android/gradlew clean 후 재빌드
