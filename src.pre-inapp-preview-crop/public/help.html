도움말

시작하기

APK: 카메라 홈이 바로 보입니다. 촬영 버튼 → 저장 모달에서 제목·메모 입력 → 저장. 카메라 권한이 없으면 촬영 시 허용을 요청하고, 거절된 경우 권한 안내 화면이 나옵니다.

웹: 저장 목록 → 앨범에서 사진 가져오기.

설정에서 일반 촬영 카메라(시스템 / 앱 내)와 연속 촬영 카메라를 고를 수 있습니다. 앱 내 카메라는 확인 화면 없이 빠르며, 미리보기에서 1x·3x·5x 배율 버튼과 핀치·더블탭으로 확대할 수 있습니다. 앱 내 촬영음은 설정에서 켜기/끄기할 수 있습니다(시스템 카메라는 기기 설정). 시스템 카메라는 화질·줌에 유리합니다.

스탬프 저장

  • 입력 칸 순서는 워터마크·별도 영역과 같습니다: 제목 → 장소(+층) → 추가1 → 추가2 → 메모.
  • 제목: 촬영 시각이 먼저 표시되고, 위치 권한 허용 시 구·동·건물명이 추가될 수 있습니다.
  • 장소: 위치 조회 「사용」이면 GPS·로컬 학교 DB·카카오 주소/POI로 장소 칸을 채웁니다. 촬영 직후 좌표만 먼저 잡히고 장소명이 비어 있으면 저장 화면에서 한 번 더 조회합니다. 「사용 안 함」이면 GPS와 로컬 학교 DB만 비교해 학교 근처일 때 학교명을 넣고, 카카오 조회는 하지 않습니다.
  • 제목·메모 표시가 사진 아래(별도 영역)이면 미리보기·PDF에 2열 표(표시명 | 내용)로 나옵니다. 값이 있는 행만 표시됩니다. 워터마크는 기존처럼 줄글입니다.
  • 설정의 글자 크기(작게·보통·크게)는 저장·수정 입력칸과 미리보기·워터마크·PDF·갤러리 이미지 저장에 함께 적용됩니다. 시스템 글꼴만 쓰며 별도 폰트 파일은 없습니다.
  • 추가1·추가2: 선택 입력 칸입니다. 값이 있을 때만 미리보기·워터마크·PDF에 「표시명: 내용」(또는 표의 행)으로 표시됩니다.
  • 층: 설정의 층 선택이 「학교일 때만」이면 장소·폴더명에 학교(초·중·고·대학 등)가 있을 때만 층 칩이 보이고, 직전 층도 학교에만 이어집니다. 비학교 장소에는 층이 저장되지 않습니다.
  • 저장 폴더: YYYYMMDD_장소명 형식. [선택]으로 기존 폴더 선택 가능. [선택] 버튼은 설정의 카메라 메뉴 위치(손잡이)와 같은쪽(왼손=왼쪽, 오른손=오른쪽)에 표시됩니다.
  • 사진 미리보기 탭 → 확대·이동으로 확인할 수 있습니다. 자르기(적용)는 현재 지원하지 않습니다. 저장되는 사진은 원본(촬영·선택본)입니다. 미리보기 확대 아이콘과 뷰어의 닫기는 설정의 카메라 메뉴 위치(손잡이)와 같은쪽(아이콘=상단, 닫기=하단)에 표시됩니다.
  • 마이크 버튼으로 제목·추가1·추가2·메모·장소 음성 입력 (APK). 칸 이름(표시명)을 탭하면 바로 바꿀 수 있고, 설정에도 저장됩니다. 저장 시점의 표시명은 그 스탬프에 함께 저장됩니다.

저장 목록

  • 카드에는 저장 당시 칸 이름(표시명)과 값이 「표시명: 내용」으로 보입니다. 메모·장소·추가 칸은 내용이 있을 때만 표시됩니다. 수정 화면에서도 그 스탬프의 표시명을 바꿀 수 있습니다.
  • 카드 탭 → 수정 · 길게 누르기 → 여러 개 선택
  • 선택 후 PDF 만들기·저장·공유, 이미지 저장, 휴지통 이동. PDF는 앱 안에도 복사되며, 선택한 사진이 속한 YYYYMMDD_장소명 폴더에 저장됩니다(여러 폴더가 섞이면 가장 많이 선택된 폴더). 폴더를 알 수 없으면 exports/에 둡니다. 공유 시트로 다른 앱·드라이브에도 저장할 수 있습니다.
  • 제목·메모 검색창 앞 마이크로 음성 검색 (APK). 헤더 「설정」에서 PDF·폴더·손잡이 등 변경
  • 내보내기 「파일명·보고서 제목」에도 마이크가 있으며, 설정의 카메라 메뉴 위치(손잡이)와 같은쪽(왼손=왼쪽, 오른손=오른쪽)에 표시됩니다.
  • 목록·휴지통은 작은 미리보기(썸네일)로 표시해 사진이 많아도 스크롤이 가벼워집니다. 수정·PDF·내보내기는 원본을 사용합니다.
  • 선택 모드에서 프로젝트 ZIP을 보내면 PC의 보고서 편집에서 열 수 있습니다. ZIP에는 사진·메타(manifest.json)만 넣고 PDF는 포함하지 않습니다(저장 속도 우선). PDF가 필요하면 목록의 「PDF」로 따로 만들거나, PC /report에서 인쇄하세요. 프로젝트·엑셀·HWPX는 기기에서 바이너리/청크 저장해 장수가 많아도 메모리 부족(OOM)이 나기 어렵게 처리합니다.

PC 보고서 편집

  • /report에서 .voicestamp.zip을 엽니다. 파일은 서버로 올라가지 않고 브라우저에서만 처리됩니다.
  • 제목·메모·층을 수정할 수 있고, 필요 없는 스탬프는 행 삭제로 뺄 수 있습니다. (열 추가·삭제는 지원하지 않습니다.)
  • 삭제·수정 후 수정 ZIP 저장·합성 JPEG ZIP·PDF 인쇄로 결과를 받을 수 있습니다. 행을 삭제하면 ZIP에 있던 기존 report.pdf는 제외됩니다.

설정

  • 설정 화면은 바로 열리며, 저장된 값은 곧 반영됩니다. 하단에 뒤로가기와 저장이 같은 줄에 고정되어 있습니다. 저장 시 바뀐 항목만 한 번에 기록해 빠르게 완료됩니다.
  • 각 선택 칩에 · 기본이 붙은 항목이 처음 설치 시 기본값입니다. 원래대로 쓰려면 해당 칩을 고른 뒤 저장하세요.
  • 필드 표시명: 제목·장소·메모·추가1·추가2 칸의 이름을 바꿀 수 있습니다(예: 공사명·현장·특이사항·담당·결과). 설정의 표시명은 새로 저장할 때의 기본값이며, 저장 화면에서 칸 이름 탭으로 바꾼 값도 설정에 반영됩니다. 각 스탬프는 저장 당시 표시명을 따로 보관해 목록·PDF·이미지·워터마크에 그대로 씁니다. 추가1·추가2는 값이 있을 때만 워터마크에 나옵니다. 비우면 기본값(제목·장소 등)으로 돌아갑니다. DB의 title/memo 등 컬럼 이름은 그대로입니다.
  • 글자 크기: 작게(85%) · 보통(100%, 기본) · 크게(125%). 입력 UI와 미리보기·내보내기(워터마크·캡션·PDF·갤러리 JPEG)에 동일하게 적용됩니다.
  • 층 선택: 사용 안 함 / 학교일 때만(기본) / 항상 표시. 층 표기: 장소 뒤에 붙이기 또는 커서 위치에 삽입.
  • PDF·폴더·카메라·위치·갤러리 등 대부분의 동작은 설정에서 변경합니다.

Android 뒤로가기

  • 목록·설정 → 카메라 (설정은 들어온 화면으로 복귀)
  • 카메라 → 앱 종료 확인

웹 제한

  • 갤러리 앨범 백업 없음
  • 카메라·음성은 브라우저·환경에 따라 제한될 수 있음

문제 해결

  • 위치가 안 나옴 → GPS·위치 권한 확인. 「사용」인데 도로명·POI가 없으면 카카오 API 키·네트워크도 확인(저장 화면에서 장소명이 비면 한 번 더 조회함). 「사용 안 함」은 학교 근처에서만 학교명이 자동으로 채워집니다.
  • 촬영이 안 됨 → 카메라 권한 허용. 거절했다면 설정 → 앱 → VoiceStamp → 권한에서 카메라를 켠 뒤 다시 시도.
  • APK 키 변경 후 → android/gradlew clean 후 재빌드
