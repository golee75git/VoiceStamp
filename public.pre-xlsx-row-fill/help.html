도움말

시작하기

APK: 처음 실행 시 온보딩 3장(찍기 → 말하기 → 저장) 뒤 「촬영 시작」으로 카메라 홈에 들어갑니다. 카메라 홈에는 VoiceStamp 키비주얼과 중앙 촬영 버튼·옆 메뉴(템플릿·목록·설정)가 있습니다. 설정의 사업 취합이 사용이면 저장 템플릿 위에 취합 아이콘이 보이며, 누르면 설정의 「시작하기 · QR·수신」과 같은 취합 허브로 갑니다(공유 링크 배너는 딥링크로 연 때만 표시). 설정의 카메라 메뉴 위치(손잡이)가 왼손이면 밝은 홈 테마(배경·설정/목록 아이콘)가 고정됩니다. 오른손일 때는 설정의 카메라 홈 배경에서 기본(검정 뒤 배경)·스타일 2(흰색 뒤 배경)를 고를 수 있습니다(처음에는 「기본」). 촬영 버튼 → 저장 모달에서 제목·메모 입력 → 저장. 카메라 권한이 없으면 촬영 시 허용을 요청하고, 거절된 경우 권한 안내 화면이 나옵니다.

웹: 홈(/) 상단 히어로에서 Android에 설치로 APK를 받거나, 본문 아래의 웹에서 미리 보기 링크(/app)로 들어갑니다. 진입 시 먼저 「웹 테스트 안내」에서 APK 전용 기능을 확인한 뒤 계속합니다. 이어서 저장 목록 → 앨범에서 사진 가져오기.

설정에서 일반 촬영 카메라(시스템 / 앱 내)와 연속 촬영 카메라를 고를 수 있습니다. 앱 내 카메라는 확인 화면 없이 빠르며, 미리보기에서 전·후면 전환·1x·3x·5x 배율 버튼과 핀치·더블탭으로 확대할 수 있습니다. 앱 내·시스템 촬영 JPEG는 스탬프 용도에 맞게 화질·긴 변 상한을 두어 저장·미리보기·연속 촬영이 가벼워집니다. 앱 내 촬영음은 설정에서 켜기/끄기할 수 있습니다(시스템 카메라는 기기 설정). 시스템 카메라는 화질·줌에 유리합니다.

카메라 홈의 저장 템플릿 아이콘(저장 목록 위)에서 용도별 템플릿을 고르면 필드 표시명(제목·장소·메모·추가1~3)이 바뀝니다. 기본 템플릿: 작업내용기록·행사기록·사고조사기록·탐구기록·여행기록·체험여행 사전답사기록·안전현장기록·공사현장기록·사진대지기록·교육활동기록·급식 위생·안전점검·학교현장지원기록·학교자산점검기록·재난·긴급 현장보고·민원현장확인기록. 행을 탭하면 바로 적용되고, 옆 「복사」로 그 템플릿을 바탕으로 내 템플릿을 만들 수 있습니다. 「내 템플릿 만들기」로 이름·표시명·입력칸 예시를 직접 정하거나, 기존 기본 템플릿을 가져와 수정해 저장할 수도 있습니다. 내 템플릿은 기기 안에만 저장되며(최대 30개), 길게 누르면 수정·삭제합니다. 기본 템플릿은 수정·삭제할 수 없습니다. 목록은 스크롤되며 상단에 「저장 템플릿」제목이 보입니다. 적용 중인 템플릿은 파란 배경으로 구분되고, 저장 화면에서 표시명을 직접 바꾼 뒤에는 사용자수정으로 표시됩니다. 저장 입력칸에는 예시가 흐리게 보이며, 촬영일시는 촬영 시각이 사용됩니다. 템플릿 적용 후 저장 화면은 처음부터 해당 표시명으로 열립니다.

스탬프 저장

  • 입력 칸 순서는 워터마크·별도 영역과 같습니다: 제목 → 장소(+층) → 추가1 → 추가2 → 메모.
  • 저장 유형: 저장·수정 화면 상단에서 유형을 고릅니다. 표시명·예시가 바뀌고, 고른 값이 다음 촬영 기본 유형으로 남습니다. 사업 취합에 연결 중이면 유형 이름 옆에 취합전송 · 사업명이 더 크게 보이며, 배지를 누르면 사업을 바꿀 수 있습니다. 유형 자체는 그대로 두고 안내만 합니다.
  • 제목: 촬영 시각이 먼저 표시되고, 위치 권한 허용 시 구·동·건물명이 추가될 수 있습니다.
  • 장소: 위치 조회 「사용」이면 GPS·로컬 학교 DB·카카오 주소·가까운 편의시설(소수 카테고리)로 장소 칸을 채웁니다. 카메라 촬영은 기기 GPS, 앨범 가져오기는 사진 EXIF GPS(있으면)를 씁니다. 좌표만 있고 장소명이 비어 있으면 그 좌표로 한 번 더 조회합니다. 「사용 안 함」이면 GPS와 로컬 학교 DB만 비교해 학교 근처일 때 학교명을 넣고, 카카오 조회는 하지 않습니다.
  • 제목·메모 표시가 사진 아래(별도 영역)이면 미리보기·PDF·갤러리 이미지 저장에 2열 표(표시명 | 내용)로 나옵니다. 값이 있는 행만 표시됩니다. 사진 둘레는 불투명 흰 배경이며, 갤러리 이미지는 네이티브 합성(불투명 JPEG)으로 저장해 흐림·초록 테두리를 피합니다. 워터마크는 기존처럼 줄글입니다.
  • 설정의 글자 크기(작게·보통·크게)는 저장·수정 입력칸과 미리보기·워터마크·PDF·갤러리 이미지 저장에 함께 적용됩니다. 시스템 글꼴만 쓰며 별도 폰트 파일은 없습니다.
  • 추가1·추가2: 선택 입력 칸입니다. 값이 있을 때만 미리보기·워터마크·PDF에 「표시명: 내용」(또는 표의 행)으로 표시됩니다.
  • 층: 설정의 층 선택이 「학교일 때만」이면 장소·폴더명에 학교(초·중·고·대학 등)가 있을 때만 층 칩이 보이고, 직전 층도 학교에만 이어집니다. 비학교 장소에는 층이 저장되지 않습니다.
  • 저장 폴더: YYYYMMDD_장소명 형식. [선택]으로 기존 폴더 선택 가능. [선택] 버튼은 설정의 카메라 메뉴 위치(손잡이)와 같은쪽(왼손=왼쪽, 오른손=오른쪽)에 표시됩니다.
  • 사진 미리보기 탭 → 확대·이동으로 확인할 수 있습니다. 자르기(적용)는 현재 지원하지 않습니다. 저장되는 사진은 원본(촬영·선택본)입니다. 미리보기 확대 아이콘과 뷰어의 닫기는 설정의 카메라 메뉴 위치(손잡이)와 같은쪽(아이콘=상단, 닫기=하단)에 표시됩니다.
  • 개인정보 가리기(Android, 설정에서 「사용」일 때): 미리보기 아래 버튼으로 얼굴·숫자 영역을 폰 안에서만 모자이크로 흐리게 한 뒤 저장할 수 있습니다. 「글자 읽어 채우기」와 같은 줄에 나란히 표시됩니다. 서버로 보내지 않으며, 기본값은 끔입니다. 약·중·강 강도는 사진 해상도·영역 크기에 맞춰 모자이크 칸이 달라집니다. 자동 감지되지 않은 곳은 사진 빈 곳을 탭해 얼굴·숫자 박스를 직접 추가할 수 있고(수동 박스는 점선, 길게 눌러 삭제), 「다시 감지」해도 수동 영역은 유지됩니다. 하단 「다시 감지」·「적용」은 시스템 내비 위에 보이도록 여백을 둡니다. 시스템 카메라 사진도 감지·모자이크 전에 회전(EXIF)을 픽셀에 맞춰 두어, 박스·블러 위치가 화면과 같게 맞습니다.
  • 사진 글자로 제목·메모(Android, 설정에서 「사용」일 때): 저장 화면 「글자 읽어 채우기」로 사진 속 글자를 폰 안에서만 읽어 제목(첫 줄)·메모(나머지) 초안을 만듭니다. 글자가 길면 저장 시트가 스크롤되고, 메모(내용) 칸 안에서도 스크롤해 전체를 볼 수 있습니다. 채운 뒤에는 메모 칸 쪽으로 화면이 내려갑니다. 서버로 보내지 않으며, AI로 문장을 새로 쓰지 않습니다. 기본값은 끔입니다.
  • 사진 URL → QR(설정에서 「사용」일 때): 저장 화면에 QR URL 칸·「연결확인」만 두고, 자세한 안내는 설정 → 사진 URL → QR에 둡니다. 칸에 https://가 기본으로 들어가며 마이크·키보드로 이어서 입력할 수 있습니다. 「연결확인」으로 접속 여부를 미리 확인할 수 있습니다(내부망·localhost는 확인하지 않음). 「URL 찾아 QR」은 Android에서 사진 글자(OCR)로 http(s)만 찾으며 서버로 보내지 않습니다. 저장 시 JPEG 우하단에 QR이 들어갑니다(「별도 영역」은 사진 안, 「워터마크」는 글자 바 위). https://만 두면 QR 없이 저장됩니다. PDF/XLSX/HWPX에는 아직 적용되지 않습니다. 기본값은 끔입니다.
  • 장면 키워드(Android, 설정에서 「사용」일 때): 저장 화면 「장면 키워드」 버튼으로 사진을 폰 안에서만 분석해 메모에 장면·사물 키워드 초안(예: 건물, 하늘)을 넣습니다. 화면이 열릴 때 자동 분석하지 않습니다. 서버로 보내지 않으며, 긴 문장 설명이 아닙니다. 기본값은 끔입니다.
  • 마이크 버튼으로 제목·추가1·추가2·메모·장소 음성 입력 (APK). 칸 이름(표시명)을 탭하면 바로 바꿀 수 있고, 설정에도 저장됩니다. 저장 시점의 표시명은 그 스탬프에 함께 저장됩니다.
  • 저장 직후 음성으로 항목 채우기(설정에서 「사용」일 때, APK): 새 스탬프 저장 화면이 열리면 「항목 말하기」시트가 뜨고 제목→장소→메모 순으로 안내합니다. 시트 상단에서 저장 유형을 바꿀 수 있고, 항목마다 템플릿 말하기 예가 보입니다. 「다음」「다시」「지금까지 넣기」「적용 없이 닫기」로 조절합니다. 필드별 마이크는 그대로 사용할 수 있습니다. 수정 화면·이음 스탬프 저장에서는 뜨지 않습니다. OS 음성 인식만 사용하며 서버로 보내지 않습니다. 기본값은 끔입니다.
  • 이음 연결: 수정 화면에서 이음 촬영·앨범 이음으로 새 스탬프를 만들고 처음과 연결합니다. 제목은 「원제목 (이음)」으로 채워지고, 장소·유형·추가 칸은 처음을 따릅니다. 목록에서는 이음이 있는 처음 제목 뒤에 (처음)이 보이고(저장 제목은 그대로), 유형 앞에 처음·이음이 붙습니다. 연결 비교에서 카드를 선택해 PDF 만들기·저장·공유·휴지통 이동을 할 수 있습니다(열면 전부 선택). 각 스탬프는 사진 1장·제목·메모를 따로 갖습니다.

저장 목록

  • 카드에는 기본적으로 제목(표시명: 내용, 굵게)·저장 유형(저장 템플릿 이름, 없으면 미분류)·날짜가 보입니다. 이음 스탬프는 유형 앞에 이음이 붙고, 이음이 달린 처음은 제목 뒤 (처음)·유형 앞 처음으로 구분됩니다. 사업 취합으로 클라우드에 올린 사진은 전송, 올리기 실패한 사진은 전송 실패, 수신함에서 내 폰으로 가져온 사진은 수신 표시가 붙습니다. 설정의 저장 목록 표시에서 「전체 표시」를 고르면 장소·추가·메모도 「표시명: 내용」으로 함께 보입니다. 수정 화면에서도 그 스탬프의 표시명을 바꿀 수 있습니다.
  • 화면 아래 갤러리·촬영 버튼은 이미지를 잘리지 않게(contain) 표시하며, 버튼 높이를 조금 키워 위·아래가 보이도록 맞춰 두었습니다.
  • 검색창 아래 유형 칩(전체 · 각 저장 템플릿 · 미분류)으로 목록을 좁힐 수 있습니다. 그 아래 장소 칩(장소 전체 · 저장된 장소명 · 장소 없음)으로 장소를 한 번 더 걸러 볼 수 있습니다. 유형·장소는 함께(AND) 적용됩니다. 예전 항목·유형을 남기지 않은 항목은 미분류입니다.
  • 저장·수정 화면에서 저장 유형을 고를 수 있습니다. 고른 유형의 표시명·예시가 입력칸에 바로 반영되고, 다음 촬영의 기본 유형으로도 저장됩니다. 카메라 홈의 저장 템플릿 아이콘으로 미리 고를 수도 있습니다.
  • 헤더 옆 앨범으로 사진을 가져오면, 사진에 들어 있는 촬영 당시 위치(EXIF GPS)로 장소·좌표를 채웁니다. 현재 기기 위치는 쓰지 않습니다. EXIF에 위치가 없거나(웹·일부 앨범) 위치 조회가 「사용 안 함」이면 장소는 비워 둡니다.
  • 카드 탭 → 수정 · 길게 누르기 → 여러 개 선택. 선택 모드에서는 체크·강조만 바꾸고 사진 미리보기는 그대로 두어, 중간 해제 때도 하얀 칸이 남지 않게 처리합니다. 취소로 선택을 끝낼 때는 목록 행을 한 번만 다시 그리고, 선택 진입 직전 스크롤을 맞춥니다(일상 스크롤·중간 해제는 그대로).
  • 선택 후 PDF 만들기·저장·공유, 이미지 저장, 휴지통 이동. PDF는 앱 안에도 복사되며, 선택한 사진이 속한 YYYYMMDD_장소명 폴더에 저장됩니다(여러 폴더가 섞이면 가장 많이 선택된 폴더). 폴더를 알 수 없으면 exports/에 둡니다. 공유 시트로 다른 앱·드라이브에도 저장할 수 있습니다.
  • 제목·메모 검색창 앞 마이크로 음성 검색 (APK). 헤더 「설정」에서 PDF·폴더·손잡이 등 변경
  • 내보내기 「파일명·보고서 제목」에도 마이크가 있으며, 설정의 카메라 메뉴 위치(손잡이)와 같은쪽(왼손=왼쪽, 오른손=오른쪽)에 표시됩니다. 이 마이크 결과는 검색창에 들어가지 않습니다.
  • 목록·휴지통은 작은 미리보기(썸네일)로 표시해 사진이 많아도 스크롤이 가벼워집니다. 저장 목록 행은 테두리·그림자를 줄이고 썸네일·행 높이를 낮춰 간격이 촘촘하게 보이며, 선택 시에만 왼쪽 강조가 나타납니다. 수정·PDF·내보내기는 원본을 사용합니다.
  • 선택 모드에서 프로젝트 ZIP을 보내면 PC의 보고서 편집에서 열 수 있습니다. ZIP에는 사진·메타(manifest.json)만 넣고 PDF는 포함하지 않습니다(저장 속도 우선). PDF가 필요하면 목록의 「PDF」로 따로 만들거나, PC /report에서 인쇄하세요. 프로젝트·엑셀·HWPX는 기기에서 바이너리/청크 저장해 장수가 많아도 메모리 부족(OOM)이 나기 어렵게 처리합니다. PDF·엑셀·HWPX·프로젝트 ZIP 모듈은 해당 버튼을 눌렀을 때 불러와, 카메라 홈 기동을 가볍게 합니다. 엑셀에는 저장 템플릿 칸 이름(제목·장소·메모·추가1~3)·저장 유형·층·좌표·촬영일시가 포함됩니다.

  • /report에서 .voicestamp.zip을 엽니다. 파일은 서버로 올라가지 않고 브라우저에서만 처리됩니다.

사업 취합 (선택)

  • 설정의 사업 취합을 「사용」으로 켠 뒤 「시작하기」로 들어갑니다. 기본값은 끔이며, 끄면 클라우드로 올리지 않습니다.
  • 관리자: 사업 만들기 → 만든 회사/사람(필수, 이 기기에만 저장·QR·서버 미포함) → 취합 PIN(숫자 6자리)·보관 기간(기본 7일) → QR·사업코드·참여코드로 공유합니다. 새 사업을 만들어도 기존 사업은 목록에 유지됩니다(최대 20). PIN을 여러 번 틀리면 잠시 잠기며, 수신·삭제·코드 갱신에만 씁니다(QR에는 없음). 허브의 만든 사업에서 사업별 초대·수신·엑셀·종료를 고릅니다. 초대 화면에서 저장 템플릿(기본·내 템플릿)을 고르면 링크·QR에 실려, 받는 사람이 참여한 뒤 촬영·저장 칸 이름·유형이 맞춰집니다(템플릿은 선택). 종료한 사업은 보관 만료일까지 「종료됨」으로 남고 수신·엑셀은 계속 쓸 수 있습니다. 사진은 앱이 한국 일시 저장소에 직접 올리고, 앱 서버는 연결·서명만 처리합니다. 공유 링크(/join)를 열면 참여 안내 페이지가 뜨고 「앱에서 참여·촬영」으로 앱에 이어지며 코드가 채워집니다(카톡 등 앱 안 브라우저에서는 버튼을 누르거나 다른 브라우저로 열기). 일반 카메라로 QR을 찍었을 때도 설치·검증된 기기에서는 앱이 바로 열릴 수 있으며, 웹 페이지가 남으면 「코드 복사」로 앱 설정 → 사업 취합 → 코드로 참여에 넣을 수 있습니다. 구분 표시 입력 후 「연결 후 촬영」하면 촬영 화면으로 갑니다(자동 촬영은 하지 않음). 수신에서 「내 폰으로」하면 앱 전용 사업 폴더에 저장되고(진행 중에는 「앱으로 가져오는 중 n / 전체」표시, 참여 시 입력한 구분 표시·촬영자 정보 포함), 수신 목록에 서버에 남은 사진과 가져온 사진을 함께 보이며 썸네일·미리보기·휴지통을 쓸 수 있습니다. 하단 「전체」「내 폰으로」「엑셀」「휴지통」을 누르면 해당 단추가 검게 표시되고, 고른 사진 왼쪽에 표시가 붙습니다. 사진을 고르지 않고 「엑셀」(또는 「내 폰으로」·「휴지통」)을 누르면 「사진을 선택한 뒤 다시 눌러 주세요」안내가 뜹니다. 「가져옴」인 항목을 선택한 뒤 「엑셀」로 보낼 수 있고(보내기 전 사진 가로 크기 px·칩 180/240/320/480/800, 기본 240·120~800, 글자 작음/보통/큼), 맨 앞 열에 촬영자(구분 표시)·템플릿 칸 이름·추가 칸·저장 유형이 엑셀에 들어갑니다(아직 안 가져온 항목은 제외). 이미 내 폰으로 가져온 항목에는 가져옴이 표시되며, 서버에서 지워져도 수신 목록에 남습니다. 사업명에 공백·점(.)이 있어도 가져온 사진은 같은 사업 수신 목록에 연결됩니다.
  • 촬영자: 공유 링크(또는 「앱에서 참여·촬영」)·코드·앱의 「QR 찍기」(카메라 미리보기·가운데 네모 안에 맞춤)로 한 번 연결하면 바로 촬영 화면으로 이동합니다(성공 알림은 생략). 초대에 템플릿이 있으면 저장 칸이 맞춰집니다. 딥링크로 연 경우 참여 코드는 자동 입력되고 구분 표시만 넣으면 됩니다. 연결이 안 되면 코드 복사 또는 앱 QR 찍기만 안내합니다. 연결 중이면 카메라 홈 촬영 버튼 위에 이 사업으로 전송 · 사업명이 보이고(누르면 취합 화면), 저장 직후 저장됨·취합 시 올리는 중·완료/실패 안내가 잠깐 보입니다. 저장 화면에도 취합전송 · 사업명과 저장 버튼 위 「이 사진이 …으로 전송됩니다」 안내가 있습니다. 이후 저장 시 제목 기본값에 사업 이름이 들어가며, 배지를 누르면 참여 이력에서 다른 사업으로 바꿀 수 있고 압축본이 한국 일시 저장소로 올라갑니다. ZIP을 따로 보낼 필요는 없습니다. 허브의 참여한 사업에서 보낸 사진으로 올린 목록을 볼 수 있습니다. 설정의 전송분 숨기기를 켜면 전송 완료분은 저장 목록에서 감추고(보낸 사진에서는 그대로), 끄면(기본) 저장 목록에도 남습니다. 연결을 끊으면 이전에 쓰던 칸 이름(템플릿)으로 돌아가고 취합전송 표시도 사라집니다. 허브의 참여한 사업에 이력이 남고, 연결을 끊어도 목록에 유지되며 다시 연결할 수 있습니다. 연결 전 구분 표시(필수)에 별칭·번호 끝자리 등 짧은 글자를 넣어야 하며, 수신 목록에 함께 보입니다. QR을 먼저 찍은 경우에도 구분 표시를 채운 뒤 「연결」을 눌러 주세요.
  • 사업 취합은 Android 앱에서만 사용합니다. 버튼을 누르면 살짝 어두워져 눌림을 확인할 수 있습니다. QR 찍기는 전체 화면으로 열리며 카메라 미리보기가 보인 뒤 가운데 네모에 관리자 QR을 맞춥니다. 웹 테스트 설정에는 취합 메뉴가 보이지 않습니다.
  • 일시 저장소 이용에는 서버(NCP) 설정이 필요합니다. 설정되지 않으면 만들기·올리기가 안내 메시지와 함께 실패할 수 있습니다. 올리기에 실패하면 안내가 뜨며, 네트워크 확인 후 다시 저장해 주세요. 운영자만 Vercel에 NCP 키를 넣으며, 앱 사용자에게 키를 요구하지 않습니다.

설정

  • 설정 화면은 바로 열리며, 저장된 값은 곧 반영됩니다. 하단에 뒤로가기와 저장이 같은 줄에 고정되어 있습니다. 저장 시 바뀐 항목만 한 번에 기록해 빠르게 완료됩니다. 위쪽에 고급 설정 펼치기가 있으며, 손잡이·위치·촬영·갤러리·글자 크기·사업 취합은 접힌 상태에서도 바로 바꿀 수 있습니다. PDF·OCR·블러 등은 고급을 펼친 뒤 조정합니다.
  • 각 선택 칩에 · 기본이 붙은 항목이 처음 설치 시 기본값입니다. 원래대로 쓰려면 해당 칩을 고른 뒤 저장하세요.
  • 필드 표시명: 제목·장소·메모·추가1·추가2·추가3 칸의 이름은 저장 템플릿 또는 저장 화면에서 칸 이름을 탭해 바꿉니다(설정 화면에는 편집 칸이 없습니다). 템플릿을 그대로 쓰면 「적용 중」, 표시명만 손보면 「사용자수정」으로 구분됩니다. 각 스탬프는 저장 당시 표시명을 따로 보관해 목록·PDF·이미지·워터마크에 그대로 씁니다. 추가 필드는 값이 있을 때만 워터마크에 나옵니다. 비우면 기본값으로 돌아갑니다. DB의 title/memo 등 컬럼 이름은 그대로입니다.
  • 저장 목록 표시: 제목·날짜만(기본) / 전체 표시. 목록 카드에만 적용되며 PDF·이미지 내보내기에는 영향 없습니다.
  • 하단 촬영 일시: 표시(기본) / 숨김. PDF·이미지의 「사진 아래(별도 영역)」맨 아래에 촬영(저장) 일시를 넣습니다. 제목 접두어(「PDF 촬영 일시 표시」)와는 별개이며, 워터마크 모드에는 적용되지 않습니다.
  • 글자 크기: 작게(85%) · 보통(100%, 기본) · 크게(125%). 입력 UI와 미리보기·내보내기(워터마크·캡션·PDF·갤러리 JPEG)에 동일하게 적용됩니다.
  • 개인정보 가리기(Android): 사용 안 함(기본) / 사용. 사용 시 저장 화면에서 얼굴·숫자 영역을 기기 내 ML Kit으로 모자이크합니다. 자동 미감지 영역은 탭으로 수동 추가 가능. 서버 전송 없음. 시스템 카메라 촬영 시에도 EXIF 회전을 맞춘 뒤 감지합니다.
  • 사진 글자로 제목·메모(Android): 사용 안 함(기본) / 사용. 사용 시 「글자 읽어 채우기」로 온디바이스 OCR 초안(첫 줄→제목, 나머지→메모). 긴 메모는 칸·시트 스크롤. 생성형 AI·서버 전송 없음.
  • 사진 URL → QR: 사용 안 함(기본) / 사용. 사용 시 저장 화면 QR URL 칸(기본 https://·마이크)·「연결확인」. 자세한 안내는 설정 문구 참고. 자동 찾기는 Android OCR·http(s)만. 서버 전송 없음.
  • 장면 키워드(Android): 사용 안 함(기본) / 사용. 사용 시 저장 화면 「장면 키워드」 버튼으로 온디바이스 Image Labeling 메모 초안. 자동 실행 없음. 생성형 문장·서버 전송 없음.
  • 저장 직후 음성으로 항목 채우기(Android): 사용 안 함(기본) / 사용. 사용 시 새 저장 화면에서 「항목 말하기」(제목→장소→메모). 시트에서 저장 유형·말하기 예 확인 가능. 수정 화면·웹 제외. OS STT만, 서버 전송 없음.
  • 저장 시 갤러리: 앱만(기본, 연속 촬영에 가장 빠름) / 원본만 / 캡션만 / 원본+캡션. 앱 목록에는 항상 저장됩니다. 갤러리 모드는 앱 저장 뒤 화면이 한가할 때 이어서 처리하며, 캡션 JPEG 합성은 한 장씩입니다.
  • 층 선택: 사용 안 함 / 학교일 때만(기본) / 항상 표시. 층 표기: 장소 뒤에 붙이기 또는 커서 위치에 삽입.
  • PDF·폴더·카메라·위치·갤러리 등 대부분의 동작은 설정에서 변경합니다. 카메라 메뉴 위치(손잡이)가 왼손이면 홈 화면은 밝은 테마로 고정됩니다. 오른손일 때 카메라 홈 배경은 기본(검정 뒤)·스타일 2(흰색 뒤)만 선택 가능하며 기본값은 「기본」입니다.

  • 웹 설정 「저장」성공·실패도 브라우저 안내 창으로 표시됩니다.

문제 해결

  • 위치가 안 나옴 → GPS·위치 권한 확인. 「사용」인데 도로명·POI가 없으면 카카오 API 키·네트워크도 확인(저장 화면에서 장소명이 비면 한 번 더 조회함). 「사용 안 함」은 학교 근처에서만 학교명이 자동으로 채워집니다.
  • 촬영이 안 됨 → 카메라 권한 허용. 거절했다면 설정 → 앱 → VoiceStamp → 권한에서 카메라를 켠 뒤 다시 시도.
  • 웹에서 스탬프 저장이 안 됨 → 안내 창 메시지를 확인한 뒤 사진을 다시 고르거나 촬영합니다. 모달이 그대로면 저장이 끝난 것이 아닙니다.
  • 웹에서 설정 저장 후 안내가 없음 → 최신 웹 빌드인지 확인합니다. 값은 저장되었을 수 있으니 설정 화면에 다시 들어가 반영 여부를 봅니다.
  • APK 키 변경 후 → android/gradlew clean 후 재빌드
